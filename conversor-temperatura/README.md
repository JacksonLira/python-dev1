# Calculadora em Python

Conversor de temperatura desenvolvida para praticar os fundamentos da linguagem Python.

## Funcionalidades

- Troca de valores
- fahrenheit para Celsius
- Celsius para fahrenheit
- tratamento de valores float
- Validação de entradas numéricas


## Requisitos

- Python 3

## Como executar

Na raiz do repositório, execute:

```powershell
python .\conversor-temperatura\conversor.py
```
