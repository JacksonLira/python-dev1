# Calculadora em Python

Calculadora de terminal desenvolvida para praticar os fundamentos da linguagem Python.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Validação de entradas numéricas
- Tratamento de divisão por zero

## Requisitos

- Python 3

## Como executar

Na raiz do repositório, execute:

```powershell
python .\01-calculadora\calculadora.py
```
